# Mercedes-Benz — In Motion

A responsive, photography-led static website concept celebrating automotive design and open-road imagery. It is an independent concept and is not an official Mercedes-Benz website or publication.

## Files

- `index.html` — page structure, content, and image references.
- `styles.css` — layout, typography, responsive behavior, and visual styling.

## Run locally

Open `index.html` in a modern browser. No build tools or JavaScript are required.

The page loads its typefaces from Google Fonts and photographs from Unsplash, so an internet connection is needed for those assets. Replace the image URLs in `index.html` with your own licensed photographs if you plan to publish the site.

## Customize

Edit the copy and image `src` attributes in `index.html`. Adjust colors, spacing, and breakpoints in the custom properties and media query in `styles.css`.
